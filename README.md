# 13병동 간호일지 자동화 웹 앱

병원 13병동(13W / 14W / 15W)의 간호일지를 매일 자동으로 작성·관리하는 **단일 HTML 파일 웹 앱**입니다.

## 🚀 사용 방법

### 실행
`index.html` 파일을 브라우저(Chrome, Edge 권장)에서 열면 바로 사용할 수 있습니다.  
외부 라이브러리 없이 순수 HTML/CSS/JavaScript로 구현되어 있으며, **인터넷 연결 없이도 동작**합니다.

---

## 📌 주요 기능

### 1. 날짜 관리
- 상단에 `2026.4.1. 수요일 (6AM기준)` 형태로 날짜·요일 자동 표시
- 날짜 선택 후 해당 날짜 기준 간호일지 조회·작성 가능
- **오늘** 버튼으로 오늘 날짜로 즉시 이동

### 2. 환자 입원 등록 (환자 관리 탭)
- 병실번호, 환자명, 성별/나이, 진단명, 신환/치료병원, 진료과, 입원 구분(신환/재입원), 비고 입력
- 병실 정원 초과 시 경고 표시
- 입력 즉시 집계 표·입원 목록에 자동 반영

### 3. 퇴원 처리
- 환자 목록에서 **퇴원** 버튼 클릭 → 퇴원일 지정 후 처리
- 해당 날짜의 퇴원 환자 목록에 자동 표시

### 4. 병실 이동
- 이동할 환자와 이동할 병실 선택 후 **병실 이동** 클릭
- 특이사항 Day 란에 `1411 백혜은 ———> 1211` 형태로 자동 기록

### 6. 특이사항 기록
- **Day / Evening** 구분하여 자유 텍스트 메모 입력 가능
- 병실 이동 기록은 Day 란에 자동 추가

### 7. 인쇄 / PDF
- **🖨️ 인쇄/PDF** 버튼 클릭 또는 `Ctrl+P`
- A4 가로 방향으로 최적화된 레이아웃 출력
- 인쇄 시 입력 버튼 등 UI 요소 자동 숨김

### 8. 데이터 저장 및 관리
- 모든 데이터는 **브라우저 LocalStorage**에 자동 저장 (새로고침해도 유지)
- **📤 내보내기**: 전체 데이터를 JSON 파일로 다운로드 (백업)
- **📥 가져오기**: 이전에 내보낸 JSON 파일로 데이터 복원

## ⚠️ 주의사항

- 데이터는 **같은 브라우저의 LocalStorage**에만 저장됩니다.  
  다른 기기나 다른 브라우저에서는 데이터가 공유되지 않으니, 정기적으로 JSON으로 내보내기(백업)를 권장합니다.
- 브라우저 캐시/데이터 삭제 시 저장된 환자 정보도 함께 삭제됩니다.
- 인터넷 익스플로러(IE)는 지원하지 않습니다. Chrome, Edge, Firefox 최신 버전을 권장합니다.
